# NovaRoma Homelab - Mainpage

Static personal portfolio and project showcase for JestingDart4369.

## Tech Stack

- **Hosting**: nginx static web server
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Deployment**: Docker + Cloudflare Tunnel

## Structure

```text
app/template/
├── index.html          # Static portfolio page
├── page.html           # Same page source kept for compatibility
├── favicon.ico
├── favicon-32.png
└── images/
    ├── Nova-roma_logo.png
    ├── favicon.ico
    └── favicon-32.png
nginx/default.conf      # nginx routes, static hosting, /health, API health proxy
Dockerfile              # nginx-based container
```

## Routes

- `/` serves the static site
- `/favicon.ico` serves the favicon directly from nginx
- `/favicon-32.png` serves the PNG favicon
- `/health` returns a static JSON health response
- `/api/check-health` proxies to the API container's `/health` endpoint for the homepage status indicator

## Local Docker Run

```bash
docker build -t novaroma-mainpage .
docker run --rm -p 8000:8000 novaroma-mainpage
```

Then open <http://localhost:8000>.

## Production

Production URL: <https://novaroma-homelab.uk>

The container is intended to run on the shared Docker Compose network with Cloudflare Tunnel pointing to `novaroma-mainpage:8000`.

## Editing projects and tech stack

`app/template/site-data.json` is the single source of truth for the tech stack, the Projects cards, the Activity repo tabs/commit feeds and the nginx allowlist for public GitHub commit feeds. Edit it, then run:

```
python3 scripts/sync_site.py
```

The static HTML and `nginx/default.conf` are regenerated from it (`--check` fails if they drift, and the test suite runs that check).

## GitHub Pages deployment

`.github/workflows/pages.yml` deploys `app/template/` to GitHub Pages on every push to `main` and refreshes `commits.json` (the Activity page data) hourly. It runs the sync check and tests first.

One-time setup:

1. Repo **Settings → Pages → Source: GitHub Actions**.
2. Preview at `https://jestingdart4369.github.io/Mainpage_Novaroma-Homelab/` (root-absolute links such as `/commits.json` only work on the custom domain, so use the custom domain for real testing).
3. **Settings → Pages → Custom domain:** `novaroma-homelab.uk`, then point DNS at GitHub Pages as described in the GitHub docs. Switch DNS last.

Pages cannot set HTTP headers, so each page ships its Content-Security-Policy as a `<meta>` tag (generated by `scripts/sync_site.py`). `frame-ancestors` is not supported in a meta tag; set it with a Cloudflare response header rule if you need it. The nginx setup (`nginx/`) keeps working unchanged: Activity falls back to the live GitHub proxy when `commits.json` does not exist.

The status indicator calls `https://api.novaroma-homelab.uk/health` directly (the API must allow the site origin via `CORS_ALLOWED_ORIGINS`).
