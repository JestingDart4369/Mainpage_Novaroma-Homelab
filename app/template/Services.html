Public endpoints hosted on novaroma-homelab.uk

Api

The main backend API for NovaRoma Homelab. Built with FastAPI and deployed via Docker and Cloudflare Tunnel. Provides clean, predictable endpoints for all services on this domain. The API is publicly accessible and designed for easy integration. All endpoints follow RESTful conventions. Authentication is handled per-endpoint as needed. The API is monitored live and status is shown on the home page. Documentation is available via the built-in FastAPI docs interface.

https://api.novaroma-homelab.uk

Other Endpoints

Additional services and tools hosted under the novaroma-homelab.uk domain. All services run in isolated Docker containers behind a Cloudflare Tunnel. Each service is independently deployed and maintained. The main website is served as a static site via the same infrastructure. Services are monitored and restarted automatically on failure. Access to internal services is restricted by Cloudflare Access where needed. New services are added as projects grow. All traffic is encrypted via HTTPS through Cloudflare.
